# 자료와 이미지

- `map/assets/*.jpg`: 경남대학교 캠퍼스투어의 건물 사진. 개별 출처는 `map/campus-data.json`에 있습니다.
- `map/assets/kyungnam-symbol.png`, 챗봇의 동일 심볼: 제공받은 경남대학교 심볼.
- `map/assets/library/`: 경남대학교 중앙도서관의 층별 도면과 기존 작업 자산.
- `map/assets/seonghun/`: 제공받은 성훈관 통합 구조도 및 추출한 층별 SVG.
- `map/campus-data.json`의 지도 윤곽·도로: © OpenStreetMap 기여자, ODbL. [저작권 및 이용 조건](https://www.openstreetmap.org/copyright).
- `docs/images/`: 개발 중인 서비스에서 직접 촬영한 화면. 사진 속 대학 이미지·심볼·도면의 권리는 각 권리자에게 있습니다.

이 저장소를 비공개로 공유하는 것은 대학 이미지·도면에 새로운 재배포 라이선스를 부여하는 행위가 아닙니다. 별도의 오픈소스 라이선스를 임의로 적용하지 않았습니다.
