# 소스 구성 안내

기존 로컬 지도와 한마 프로젝트를 `map/`, `chatbot/`으로 모았습니다. 실행 코드는 그대로 복사했고, 복사한 파일의 SHA-256은 루트의 `SOURCE_MANIFEST.json`에 기록했습니다. 원래 실행 중인 프로젝트는 변경하지 않았습니다.

추가한 것은 통합 README, 실행·자료 안내, Git 제외 규칙, 화면 사진과 재배치한 지도 테스트입니다. 지도 테스트는 새 폴더 구조에 맞춰 경로만 변경했습니다.

다음 파일은 포함하지 않았습니다.

- 약 646MB의 `kyungnam.db`, 수집 JSONL와 생성된 평가 보고서
- `.env`, 로그인·인증 파일, API 키, 로컬 `.runtime.json`
- 가상환경, 캐시, 실행 로그, 프로세스 번호와 임시 공개 주소
- 개인 PC의 바탕화면 바로가기와 해당 PC의 작업 폴더를 전제로 하는 시작·종료 스크립트

재사용 가능한 지도 서버와 공유 게이트웨이, 챗봇의 설정·시작·종료·검증 스크립트는 포함했습니다. 수집기의 기존 `config.json` 대신 허가 상태를 `false`로 둔 `config.example.json`을 제공합니다.

DB 없이 지도는 실행할 수 있습니다. 한마 전체 실행 및 DB 기반 평가는 별도의 DB가 필요합니다. 원본의 운영 모델·인증 방식을 다른 방식으로 바꾸지는 않았습니다.
